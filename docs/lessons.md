# Lessons

What this project's past changes taught us. Read all of this before changing an API, a format or an
agreed behaviour here. For the full story of a line, find the entry with the same date and name in
`lessons-full.md`.

When one has to change, add the full entry to `lessons-full.md` and one line here, newest last, in the
same commit as the change. Keep this file under 20 KB: at the cap, merge lines before adding.

- **2026-11-05 A list of paths names paths, not just files**: when a second input route joins an existing one, ask what its input means before reusing the rule; when two inputs can land on one output, name what the operator meant by each and decide the winner once, before any work starts.
- **2026-11-06 A landing is a path too**: for every path a run writes, ask what else the run reads there; refuse a source landing on another source's path (or inside it, or on a directory holding it) once, before any copy, in every mode.
- **2026-11-06 Judge the thing you protect**: a safety check on data asks its question of the files, by real path, from what the run will really do; one built on roots and spellings is wrong both ways, and two checks asking one question must share one answer.
- **2026-11-06 A landing never leaves its destination**: a path part with no name of its own ('.', '..') gives nothing to land under; joining it as a name made `hpcp .. -d out/` write beside `out/`.
- **2026-11-06 A write goes to an inode, not a path**: an option that writes in place writes every name of that file; a check by path cannot see a hard link, so the writer has to leave it.
- **2026-11-06 Ask the rule that decided, not the spelling**: 'a source that is the destination' splits on where it lands, so ask the landing rule; `a` lands under itself and can go, `a/` lands on itself and must stay judged, and a copy of the rule on the text gets that backwards.
- **2026-11-06 'None' and 'could not look' are two answers**: an empty set from a failed scan reads as 'no links'; a check keeps three answers (no, yes, unknown), asks another way when it can, and refuses, naming the fix, only at a question that needs the answer and nothing can give it.
- **2026-11-06 Clean up what you made**: a cleanup after a failure first proves the failed step made what it removes; a destination that was there before looks just like a part of a copy.
- **2026-11-06 A node is not its contents**: `cp -f` opens what it is given, so a mode that copies contents takes regular files only; and the safe route for a node (`cp -a`) unlinks what is there, so what the operator named as the destination is judged before it, once, by asking `_source_dest` where the source lands.
- **2026-11-06 A refusal is as narrow as its reason**: record a refusal against what the reason is about (one destination, one file), not the job around it; ask what a name leads to (`stat`) and whether the tool runs at all before saying what it would do; a permission that decides data loss is asked by doing it, before the step that takes the old data.
- **2026-11-06 A name that matched nothing is still a name**: a pattern expander that returns only matches loses the names the operator typed; keep the name so the one check that reports a missing source sees it, and decide per route what a missing source means: a name typed now is an error, a list entry may simply be older than the tree.
- **2026-11-06 A name is what the destination reads**: two strings are two names only to a filesystem that says so, and each has its own rules; cast a wide net in memory, then ask the directory about the actual pair by doing it. Asking 'does this destination fold?' once gave a false refusal, missed what lay below the top, and wrote on every run; and a check by name needs a check by identity beside it, or a mirror deletes what the copy just wrote.
- **2026-11-06 Could not compare is not a crash**: a check that may skip work treats a read it was refused as 'not known to be the same' and goes on to the step that reports it; only the refusal, as any other read error reaches a tool that truncates first.
- **2026-11-06 One door for a directory**: the flag that skips a step must not skip what the step refused; the refusal and the making of a directory are one helper, or the second route ends in a traceback.
- **2026-11-06 A refusal offers a fix its reader can run**: name the thing in the reader's own tree (the link), not only where the walk stopped, which can belong to anyone; and give the command in a form its shell runs: quote names for the shell, not as the program holds them.
- **2026-11-06 The reason travels with the error**: a runner that knows what a tool said puts it in the error it raises, or every caller reports only a return code.
- **2026-11-07 Different numbers prove nothing**: equal st_ino means one file, but a filesystem may number each spelling of one name (exFAT through FUSE, CIFS noserverino); whether two names are one is asked by doing it, and a listing answers only where nothing can be made.
- **2026-11-07 A cheaper filter is no narrower net**: speed up a safety check by making it cheaper, never by a cheaper rule in front of it that is not a superset of it (lowercasing is not folding: it let a landing through a link, and `σ`/`ς`, through).
- **2026-11-07 Ask the whole group at once**: when a wide net groups candidates for a costly question, ask about the whole group in one go and keep the answer for the run, or the cost is the square of a group that safety keeps large; a reason names what failed, the name or the place.
- **2026-11-07 A net over bytes is cast per byte**: a rule about bytes is applied to the bytes, not to what a lenient decoder makes of them (`replace` read cp1251 `Пё` as UTF-8 and its other case as marks); and a check that could not tell says so, not the answer it would give if it could; and where another table decides, nothing it could map is fixed, ASCII letters and punctuation included (iso8859-9 makes `i` the other case of `İ`; a cp932 character can end in `@`).
- **2026-11-07 Check what landed before removing what it came from**: before a step destroys the only copy, check the result it depends on by what is there (size, time, identity), after the step that made it; checks that predict from names stay to refuse early, but none of them is complete where the filesystem decides.
- **2026-11-07 A mirror judges only what a source speaks for**: a cleanup judges only below where a source lands, and asks of each thing it would remove what it is (identity), not where it was found: whatever is a source, lies in one or holds one is never extra.
- **2026-11-07 A tolerance is sized on every filesystem it meets**: when a check's miss turns from a re-copy into a refusal, measure its tolerance on each filesystem (vfat 2 s, exFAT 10 ms, UDF 1 us, NTFS 100 ns, none before 1980 on vfat); compare the integers the filesystem stores, not a float of them, allowing one float step where a time may have passed through one; and where the cheap evidence cannot exist, read instead of refusing.
- **2026-11-07 A guard takes the operator's words, not a filter's output**: build a safety check from what the operator named, before any step that narrows it for another purpose (a list entry left in place is still a source); and ask each question at the level its answer lives at, once a directory, not once a file below it.
- **2026-11-08 A write never goes into what is there**: give a copy tool a new name, not the landing; what is at the landing (an old copy, a FIFO, a device, a link) is replaced once the new file is whole, and only what the operator named is followed or written through.
- **2026-11-08 In place only after the source has read to its end**: a fallback that writes into the old copy first proves the source reads whole and that the rewrite needs no space it does not have; anything else keeps the old copy, and what cannot be replaced is refused, never written through.
- **2026-11-08 A stop is a cleanup**: every process that leaves a temporary file turns each stop it can catch into its cleanup path and then ends as the signal asked; a signal it was started ignoring stays ignored, and a watch that sees the main process gone (by its sentinel, not getppid) stops the main thread with a signal of its own before it exits.
- **2026-11-08 A link below a destination is a name**: a check that follows it has to predict where every write goes; replacing it leaves nothing to predict, and the scan that found links goes with it.
- **2026-11-08 Only a directory holds what lies below it**: a spelling that puts a path below a link or a file names no containment; ask what the root is before reaching through it, and remove a link after what was reached through it.
- **2026-11-08 A special the operator names is a source**: a refusal by type belongs to a walk that meets it, not to a name the operator typed (but see 2026-11-13 for a socket on macOS).
- **2026-11-08 A probe costs only its names**: make what you ask a directory about relative to its descriptor, or the question fails where the answer would not.
- **2026-11-08 A rename is not a barrier**: data renamed over a good copy, or a source unlinked after its copy, reaches the disk in no promised order; fsync what you rename over something, and each file a move copied before removing anything.
- **2026-11-09 Check a write while its data is still held**: syncfs before Linux 5.8 reports no write error, and a writeback error is kept only on the in-memory inode, which dies when it is evicted (a long job's own memory pressure does it); so a check made at the end can only see what the kernel still remembers. fsync each file right after writing it, on its own descriptor, and treat a failure as a failed copy.
- **2026-11-09 A safe route that cannot always run is as safe as its fallback**: before making a safer route the default, list where it cannot run and what happens there; a fallback that redoes the old route cleverly brings back its losses and adds new ones, so keep the old route as the default, take the safe one where the old could corrupt, and offer it as an option.
- **2026-11-09 A path we resolve ourselves skips the kernel's checks on the way**: the kernel checks a link while it follows it (`fs.protected_symlinks`, an LSM); `realpath` and the path it returns skip that, so let the kernel do the step, or ask it first by doing the real thing once (a `stat` through the link).
- **2026-11-10 A directory's metadata goes on after its contents**: setting a directory's mode and times before writing into it refuses a read-only directory's files and leaves every written directory with the copy's time; make the directory with what lets its contents in, and give it its times, exact mode and flags after them, deepest first.
- **2026-11-10 A space check counts the work it will do**: `-enes` compared a source's listed size with the free space before it knew what was already there, so a rerun with nothing to copy was refused; count what the run will write (what is not already the same, less the room an old copy rewritten in place frees), and only where the cheap total says it may not fit.
- **2026-11-10 A child writes the parent's held file through its own inherited descriptor**: naming another process's `/proc/PID/fd/N` works only on Linux and only where that `/proc` shows the process to the child; pass the descriptor (`pass_fds`) and let the child name its own (`/proc/self/fd/N`, `/dev/fd/N`), and ask once by doing the real copy on a scratch file and reading back what it left (on macOS the reopen is a `dup`, which ignores `O_TRUNC`). Give a file you made its owner after the data, as `cp -a` does: given first, an owner's quota is charged for the write.
- **2026-11-10 A look again is judged as the first look was**: a retry that takes a fresh look at a landing (the create said the name is taken) skipped the guards the first look went through, so a planted dangling link was written through by a root run; put the rules in one function every look calls.
- **2026-11-10 A pool sized by what it waits on keeps a floor, and the CPU count is only a ceiling for CPU work**: a move's workers wait on fsyncs, so 4 a CPU was right on 2 and 4 vCPUs and 20 to 45 % slower than 32 workers on 32 CPUs with a fast disk; use a floor measured on the slow case (16), never fewer than the version before, and test a default on a small and a big host.
- **2026-11-10 A list of file names holds each name's own bytes**: UTF-8 round-trips a name only where the filesystem's encoding is UTF-8 or ASCII; under Latin-1 or EUC-JP a patch made and applied by the same build was refused. Write and read names with the filesystem's encoding, keep tool output (labels) UTF-8, and test the pair under a locale that is neither.
- **2026-11-10 An empty argument is a question, not a path**: `normpath('')` is `.`, so `-d "$UNSET"` spilled a source into the working directory without the question 9.86 asked; a path normaliser skips the empty value.
- **2026-11-10 A crash is the failure of the source it crashed on**: a catch-all handler that only printed left a later check to report the source as copied but at none of its landings (213); record the failure for that file in the one place later checks read.

- **2026-11-10 A reader keeps reading what earlier releases wrote**: 9.87 changed how a patch's change list spells names and read every list the new way, so a 9.86 patch under Latin-1 was refused, or its deletions skipped with exit 0; when a writer changes, the reader asks who wrote the file (the manifest's `hpcp_version`) and reads each as its writer wrote it.
- **2026-11-10 A guard over imports is scoped to the imports, and released on every path**: a mask taken at a module's top and released at its end stays held when any line between fails; gather what it guards into one `try` whose `finally` releases it, and keep the rest of the import free of work (a subprocess) the guard would have to stretch over.
- **2026-11-10 Store what C made before Python can raise**: a signal handler runs right after a C call returns, so `fd = os.open(...)` can lose the descriptor and leave the file for any handler; let C store it (`list.extend(map(partial(os.open, ...), (name,)))`), clean up only what the stored handle proves was made, and remove a name as soon as it has served, not only in a `finally` the first stop can cut.
- **2026-11-10 Key work by where it lands, not where it comes from**: two sources that land on one directory are one directory: key a sync by its destination, keep the later source's as merged files do, count a root among its folders, and judge a stored time within the step the destination keeps, not the source's.
- **2026-11-10 A mode that shuts the runner out is set after every step that looks below it**: a non-root move gave a directory its 0607 at the finish, then its own fsyncs and checks reached below it by path (212 where the copy was whole); set such a mode last, deepest first, and let a stop before it leave the wider mode.
- **2026-11-11 A destination the operator named is pinned for the run**: following a named link "as cp follows its argument" was decided for one open, but a run opens it in many processes over hours, so whoever could rename it chose where a root run wrote; resolve what the operator named once, at the run's start, and have every later open check it still leads there (refused with 213, said once a process, counted for each file), and keep what you pinned open for the run, or a mount that expires meanwhile comes back as another object.
- **2026-11-11 A remembered look is a window**: 9.87 checked the way to a landing once a process and then wrote by path, so a directory on the way swapped for a link led a root run's files elsewhere; hold the object you checked (a descriptor), never its name, from the place the operator named down, and make every name relative to what you hold.
- **2026-11-11 A copy you carry is no requirement**: declare only what the program needs from outside it; a library it embeds and picks by version at import needs no install requirement, and one left behind guarantees nothing while the installer's failures (pip 9's eager upgrade of an old multiCMD, `DuplicateOptionError`) stop your install.
- **2026-11-12 A look and a repair are two doors**: the walk that makes the way to a landing replaces a link on it, so a pass that only looks at what the run wrote (a move's fsyncs) replaced the move's own links; give the walk a mode that changes nothing and answers "not there" where a repair would act, and have each caller say which it wants; and measure a guard that moves a pass's calls from threads into one thread where each call is a round trip (it made a move's directory fsyncs about 5 to 11 times as long, and went back out).
- **2026-11-13 What the platform cannot make whole, a copy leaves out and says so**: macOS has no call that makes a socket below a held directory and no descriptor of one, so 9.90's builds made it by name in a directory of their own, and the reviews and the design check found six ways through that name (a swap of the directory, its inherited ACL); before building what the platform's own `cp` does without, ask what the result is worth (an inert name) and what its making must trust (a name), and where the answer is a name, skip it with the note a walk gives.
- **2026-11-13 A name you made is not the thing you made**: the name probe made a directory by name, then listed whatever stood at that name and unlinked it, so a directory or link another user put there in between lost its files; open what you made by a descriptor, check it is what you made (empty, and giving its owner to a file you make in it), do every later step through what you hold (the undo, only once that check has passed; the times, taken from what you hold), never follow or wait for a name someone else can put there, and when one call of a function trusted a name, read its other calls the same day. (But see 2026-11-13 "An undo that cannot destroy needs no proof": the probe no longer needs the check.)
- **2026-11-13 A conversion that answers 0 for what it cannot read is no check**: a size option went to `format_bytes`, which answers a word with 0 and an unknown unit with `None` (by version) and reads the front of a text with anything after it, so `-ddr one` wiped a partition table and `-L 1,5M` set a copy's limit to 1 byte a second; judge the text with your own strict rule first thing in the run, before any effect, convert it once, and test the rule against the converter over the same strings. Where an old reading was harmless and scripts rely on it (`-L ''`: no limit), keep it and say it, on stderr; what holds a digit is a number, read or refused.
- **2026-11-13 An undo that cannot destroy needs no proof**: the probe guarded an undo that unlinked what it found, by proving what stood at a name; make the thing so that its undo is an operation that removes nothing of value (`mkdir`, then `rmdir`), and the proofs, with their rounds, have no job.
- **2026-11-13 A tool that writes can put back what its write cleared**: macOS's cp puts back the mode it found, so the set-ID bits its writes cleared came back under -co; check the file after the tool's whole run against what a plain write leaves (asked by doing one), and keep a kernel's rule for that kernel (macOS runs set-group-ID without group execute).
